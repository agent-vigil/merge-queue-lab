# Agent Vigil merge-queue lab

This public repository exists to test one claim: an Agent Vigil check owned by
an external GitHub App can stop a failing merge-queue head and approve a
passing one without trusting workflow changes from the pull request.

The repository is first-party test infrastructure. Its runs are public proof
of deployment behavior, not evidence of external adoption or revenue.
Public test repository for Agent Vigil merge-queue enforcement.
